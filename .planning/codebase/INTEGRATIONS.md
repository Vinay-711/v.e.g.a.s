# External Integrations
Last Mapped: 2026-07-09

## External APIs & Services
- **LiveKit Cloud:** WebRTC server for real-time voice connections.
- **Google AI / Gemini:** Cognitive LLM processing.
- **OpenAI:** Text-to-Speech (TTS) voice generation.
- **Sarvam.ai:** Speech-to-Text (STT) transcription.
- **Supabase (Optional):** Database for state/memory.
- **Groq & Deepgram (Optional):** Alternative AI providers.

## Internal APIs
- **MCP Server:** FastMCP server exposing tools (web search, news, system info) locally on `http://127.0.0.1:8000/sse` via Server-Sent Events (SSE).
